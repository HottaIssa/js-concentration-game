# js-concentration-game

 Enter for play : https://hottaissa.github.io/js-concentration-game/index.html

js-concentration-game is a simple concentration game built using HTML, CSS, and JavaScript. The game challenges the player's memory and concentration skills by presenting a grid of cards with random numbers. The objective is to click on the cards in ascending order to reveal the correct numbers and complete the game.

## How to play
1. Open the `index.html` file in your web browser.
2. Click on the "INICIAR" button to start the game.
3. Click on the cards to reveal the numbers. If you click on a card with a number that matches the current target number, the card will turn green for a short time to indicate a correct answer. If you click on a card with a number that is lower than the current target number, the card will turn red for a short time to indicate an incorrect answer.
4. As you progress through the game, the target number will increase. Keep clicking on the cards to reveal the correct numbers and advance through the game.
5. The game ends when you click on a card with the number 99, which is the final target number. At this point, the stopwatch will stop counting, and a message will appear on the screen congratulating you for completing the game.
6. After completing the game, the game will reset, and you can start a new game by clicking on the "INICIAR" button again.
